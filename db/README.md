# Modul Database SCOUT

Direktori ini memuat definisi skema data dan seed awal untuk platform SCOUT (Securities Crowdfunding Companion).

## Berkas:
- `schema.ts`: Definisi antarmuka model profil UKM, dokumen persyaratan SCF POJK 57/2020, log asesmen kesiapan, dan data platform SCF mitra berizin OJK.
- `seed.ts`: Kumpulan data bawaan (*preset*) untuk platform penyelenggara SCF mitra berizin OJK (Bizhare, Santara, Shafiq, LandX).
