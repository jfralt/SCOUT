# Wireframe US-04: Unggah Dokumen dan Progres Kelengkapan

**User story:** Sebagai pemilik UKM calon penerbit, saya ingin mengunggah dokumen dan melihat progres kelengkapannya, agar saya tahu mana yang sudah lengkap dan mana yang masih kurang.

**Acuan:** flowchart Checklist Dokumen (cek login dan privasi → tampil progres → pilih dokumen → pilih file → pratinjau → kirim → progres terbaru).

Wireframe dibuat dengan tampilan ponsel (mobile-first), karena file dipilih dari ponsel atau kamera.

---

## Daftar Layar

| Kode | Layar | Keterangan |
|------|-------|------------|
| W-04.1 | Ajakan Setujui Kebijakan Privasi | Jika privasi belum disetujui |
| W-04.2 | Error Muat | Halaman gagal dimuat, ada Coba Lagi |
| W-04.3 | Checklist Dokumen | Progres kelengkapan dan daftar dokumen dengan status |
| W-04.4 | Rincian Dokumen | Keterangan dokumen dan tombol Unggah |
| W-04.5 | Pilih File | Pilihan sumber: ponsel atau kamera |
| W-04.6 | Error Format/Ukuran | File tidak sesuai ketentuan |
| W-04.7 | Pratinjau dan Kirim | Cek file sebelum dikirim |
| W-04.8 | Proses Unggah | Indikator proses |
| W-04.9 | Unggahan Gagal | Pesan gagal dan Coba Lagi |
| W-04.10 | Progres Terbaru | Status jadi Sudah diunggah, progres dihitung ulang |

**Prasyarat akses (tanpa layar baru):** jika belum login sebagai penerbit, pengguna diarahkan ke halaman login (lihat US-01, W-04 pada wireframe registrasi dan login).
