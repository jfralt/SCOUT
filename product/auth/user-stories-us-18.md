# User Stories

## US-18 Disclaimer dan Syarat Ketentuan (F-18)
- Prioritas: Must | Ukuran: S | Sprint: minggu ini
- Sebagai pengguna, saya ingin melihat pernyataan batas layanan SCOUT
  dengan jelas, agar saya tidak salah paham bahwa hasil SCOUT menjamin
  diterima atau merupakan saran investasi.

### Acceptance Criteria
1. Given saya membuka halaman syarat dan ketentuan, Then tampil aturan
   pemakaian SCOUT.
2. Given hasil penilaian atau kecocokan tampil, Then di halaman itu ada
   pernyataan hasil bersifat indikatif dan bukan jaminan diterima.
3. Given hasil penilaian tampil, Then ada pernyataan bahwa skor kesiapan
   bukan skor investasi.
4. Given pernyataan tampil, Then ada penjelasan bahwa pengajuan resmi
   dilakukan di platform penyelenggara.
5. Given saya mendaftar, Then ada tautan ke syarat dan ketentuan di form
   pendaftaran.
