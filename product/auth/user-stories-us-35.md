# User Stories

## US-35 Halaman Detail Penyelenggara (F-35)
- Prioritas: Must | Ukuran: S | Sprint: berikutnya
- Sebagai pemilik UKM calon penerbit, saya ingin membuka halaman detail satu
  penyelenggara, agar saya memahami persyaratan, biaya, dan prosesnya
  sebelum memilih.

### Acceptance Criteria
1. Given saya menekan nama penyelenggara dari daftar atau hasil kecocokan,
   Then halaman detail penyelenggara terbuka.
2. Given halaman detail tampil, Then ada profil singkat, jenis efek yang
   didukung, persyaratan umum, dan estimasi biaya.
3. Given akun FREE, Then hanya informasi dasar yang tampil dan bagian
   lengkap terkunci.
4. Given halaman detail tampil, Then ada tombol Pilih Sebagai Tujuan yang
   mengisi penyelenggara tujuan di profil saya.
5. Given halaman detail tampil, Then ada keterangan tanggal data diperbarui
   dan pernyataan bahwa pengajuan resmi dilakukan di penyelenggara.
