# User Stories

## US-15 Navigasi Menu dan Tampilan Responsif (F-15)
- Prioritas: Must | Ukuran: M | Sprint: minggu ini
- Sebagai pengguna, saya ingin berpindah antar halaman lewat menu yang
  jelas dan nyaman di ponsel, agar saya tidak bingung memakai aplikasi.

### Acceptance Criteria
1. Given saya sudah login, Then menu menampilkan Dashboard, Profil Bisnis,
   Dokumen, Kecocokan, dan Akun.
2. Given saya menekan sebuah menu, Then halaman yang sesuai terbuka dan
   menu aktif ditandai.
3. Given layar ponsel, Then menu berubah menjadi menu ringkas (misalnya
   ikon hamburger atau bottom navigation) dan isi halaman tidak terpotong.
4. Given fitur terkunci karena tingkat layanan, Then menu tetap tampil
   dengan penanda kunci.
