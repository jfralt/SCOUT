# User Stories

## US-14 Beranda (F-14)
- Prioritas: Must | Ukuran: S | Sprint: minggu ini
- Sebagai calon pengguna, saya ingin melihat halaman beranda yang
  menjelaskan SCOUT, agar saya paham manfaatnya sebelum mendaftar.

### Acceptance Criteria
1. Given saya membuka alamat aplikasi tanpa login, Then tampil beranda
   berisi penjelasan singkat SCOUT dan empat tahap layanannya.
2. Given beranda tampil, Then ada tombol Daftar dan Login yang berfungsi.
3. Given saya sudah login, When saya membuka beranda, Then saya diarahkan
   ke dashboard.
4. Given beranda tampil, Then ada pernyataan bahwa SCOUT bukan
   penyelenggara SCF.
